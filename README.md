# LEBENAR® · Crecer ayudando a crecer

Plataforma de formación de Leonel Benítez. Sitio estático, sin dependencias ni proceso de compilación.

## Contenido y uso

Tres caminos: conocer el proyecto, primeros pasos y socios. Siete recursos de formación conservados desde la versión de Sites: audios, videos, guía y biblioteca. Buscador, guardados, notas y progreso local en el navegador. Los enlaces externos conservan sus permisos. No se copian documentos ni bases de usuarios al repositorio.

## Publicación

GitHub Pages sirve la raíz de main. CNAME se conserva sin modificaciones. Los assets originales permanecen en assets/images. La copia de Sites conserva su acceso privado; GitHub Pages sirve esta versión con acceso público. Los accesos anteriores proyecto.html, primeros-pasos.html y socios.html redirigen a sus secciones actuales. La mesa de control conserva su página y estilos anteriores; no hay administración ni autenticación de socios en este sitio estático.

## Validación del 24/10/2026

Sintaxis JavaScript; identidad, imágenes y catálogo; portada sin desbordamiento horizontal en anchos de contenido de 320, 360, 390 y 430 px; secciones interiores a 320 px; menú móvil, flechas y teclado del carrusel. Controles principales de 48 px. Los textos de acceso se adaptan al alojamiento público. No se cambiaron permisos de recursos externos ni DNS.

No guardar cuentas, contraseñas, bases de usuarios ni información privada en este repositorio público.
